这是 `yt_dlp_gui` 的 Windows 原生正式版，使用 C#、.NET 10 与 WPF 重构。

主要功能：

- 视频、AAC 音频、人工字幕、自动字幕与 YouTube 播放列表下载
- H.264 优先与最佳兼容模式
- Bilibili 常规嗅探失败后的网页/API 直连回退与 FFmpeg 合并
- 完整进程树取消、临时 Cookie、可选浏览器登录态与 yt-dlp 在线更新
- 默认下载到主程序同级 `Downloads`，自定义目录可持久保存
- 深色、浅色、跟随系统三种主题，弹窗与主界面保持一致

发布验证：

- 45/45 个确定性测试通过
- YouTube 与 Bilibili 两项真实网络测试通过
- Release 构建 0 warning / 0 error
- 深色、浅色、跟随系统及主题化弹窗已完成视觉检查

下载：

- `YtDlpGui.Native-2.0.0-win-x64.zip`：Windows 10/11 x64 自包含正式包，无需预装 .NET
- `YtDlpGui.Native-2.0.0-ffmpeg-source.zip`：随包 FFmpeg 对应源码与构建脚本快照
